A free Pixel Screenshots and MyMind alternative for iPhone, Android, and Web

Google's Pixel Screenshots app proved how useful on-device AI is for making messy screenshots searchable. The limitation is obvious: it only runs on newer Pixel phones. On the other side, visual bookmarking tools like MyMind work across devices, but require a paid subscription and upload your captures to remote servers.

Built for every device you actually use

Tuck brings private screenshot triage to Web, Chrome, Android, and iOS in one free, open-source project. On Chrome and supported Android phones, Firebase AI Logic runs Gemini Nano locally. On iOS, it targets Apple Foundation Models. On devices without a local model, it falls back automatically to Cloud Gemini so nothing breaks.

Privacy enforced at the database layer

When you toggle "Private (keep on-device)" on a dentist receipt, lab report, or chat screenshot, Tuck strips the raw image before syncing to Firestore, and Firestore Security Rules reject any write that tries to attach image data to a private item.
